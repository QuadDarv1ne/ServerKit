**Развертывайте, управляйте и мониторьте серверы.**

## 🚀 Быстрый старт

> Время установки зависит от сервера, сети и необходимых пакетов.

### Вариант 1: Установка одной строкой (рекомендуется)

```bash
curl -fsSL https://serverkit.ai/install.sh | bash
```

> Работает на Ubuntu 22.04+, Debian 12+, Fedora и RHEL/Rocky/AlmaLinux 9+. Настраивает всё автоматически.
>
> Опционально: `PANEL_DOMAIN=panel.example.com` задаёт домен и пытается использовать Let's Encrypt; `SERVERKIT_OFFLINE_TARBALL=...` устанавливает из локального tarball.

### Обновление

```bash
sudo serverkit update
```

Атомарное blue/green обновление с предварительными проверками, резервным копированием БД, миграцией и автоматическим откатом. Используйте `--dry-run` для предпросмотра, `--branch dev` для dev-сборок или `--release [version]` для релизных tarball.

### Вариант 2: Docker

```bash
git clone https://github.com/jhd3197/ServerKit.git
cd ServerKit
cp .env.example .env       # затем отредактируйте .env, указав свои секреты
docker compose up -d       # доступ по адресу http://localhost:5000
```

Запускает панель как один контейнер. Обратите внимание: панель в контейнере **не может управлять своим хостом** — нет systemd, нет хостового nginx, нет управляемых виртуальных хостов сайтов; для этого используйте Вариант 1. Она поставляется без nginx и никогда не перенаправляет на HTTPS, что делает её подходящей целью для размещения вашего собственного обратного прокси перед ней — см. [Работа за собственным обратным прокси](docs/INSTALLATION.md#running-behind-your-own-reverse-proxy).

### Вариант 3: Ручная установка

См. [Руководство по установке](docs/INSTALLATION.md) для пошаговых инструкций.

### Требования

| | Минимум | Рекомендуется |
|---|---------|-------------|
| **ОС** | Ubuntu 22.04+ · Debian 12+ · Fedora · RHEL/Rocky/AlmaLinux 9+ | Ubuntu 24.04 LTS |
| **Архитектура** | x86_64 · ARM64 | x86_64 · ARM64 |
| **ЦП** | 1 vCPU | 2+ vCPU |
| **ОЗУ** | 1 ГБ | 2+ ГБ |
| **Диск** | 10 ГБ | 20+ ГБ |
| **Docker** | 24.0+ (опционально для самой панели) | Последняя версия |

> Эти требования — рекомендации по sizing, а не эталон производительности. Предусмотрите дополнительную ОЗУ и диск для управляемых приложений, образов, баз данных, логов и резервных копий. Измерьте свою нагрузку с помощью [руководства по измерениям](docs/METRICS.md).

## 🏗️ Архитектура

<img width="100%" alt="Архитектура ServerKit: клиенты и публичные посетители достигают пограничного слоя nginx, который разделяет трафик панели на Flask API, а публичный трафик — на контейнеры приложений; панель ServerKit содержит React SPA, REST API, шлюз агента Socket.IO, сервисы, модели, задания, уведомления и среду выполнения расширений; слой среды выполнения на том же сервере содержит контейнеры приложений Docker, базы данных и состояние панели; удалённый флот агентов Go подключается обратно через пространство имён /agent." src="docs/images/architecture/system-overview.png" />

**Nginx** терминирует TLS и разделяет трафик двумя способами: запросы панели идут в **Flask API**, всё остальное проксируется в **Docker-контейнер**, обслуживающий этот домен. Панель хранит своё состояние в SQLite или PostgreSQL, выполняет фоновую работу через планировщик заданий и шину уведомлений, а опциональную функциональность загружает из **среды выполнения расширений**. Удалённые серверы управляются **агентом на Go**, который подключается обратно через пространство имён Socket.IO.

## 🔭 Связанные проекты

**[Faro](https://github.com/jhd3197/faro)** — Современный десктопный клиент для SFTP, FTP, SSH и S3-совместимого хранилища от того же автора. Сохраните сервер один раз, затем просматривайте его файлы в двухпанельном режиме и открывайте терминал в той же SSH-сессии — плюс перетаскивание файлов, односторонняя синхронизация каталогов и редактирование на месте. У него даже есть **Agent Bridge**, который позволяет Claude Code (или любому MCP-агенту) выполнять команды на машине через вашу аутентифицированную сессию, с подтверждением каждой команды и без общих учётных данных.

> ServerKit управляет вашими серверами из браузера; Faro — десктопный компаньон для ручной передачи файлов, оболочек и разовой работы на всех ваших машинах. [Скачать сборку →](https://github.com/jhd3197/faro/releases/latest)

**[LocalKit](https://github.com/jhd3197/LocalKit)** — Запускайте локальные сайты WordPress в один клик. Каждый сайт работает как отдельный изолированный проект Docker Compose, и вы можете отправлять код или push/pull базы данных прямо на ваш сервер ServerKit через расширение `serverkit-localkit`.

**[DeviceKit](https://github.com/jhd3197/DeviceKit)** — Унифицированная платформа для флота Android-устройств и автоматизации тестирования. Управляйте флотом устройств из одной панели — запускайте автоматизации, транслируйте экраны в реальном времени, отслеживайте визуальные регрессии и отлаживайте сбои с помощью анализа на основе ИИ.

**[Vela](https://github.com/jhd3197/vela)** — Ваш персональный сервер приложений. Устанавливайте, запускайте и управляйте локальными приложениями из одной панели в браузере, пока ваши приложения, настройки и данные остаются на вашей машине — с самообновляющимися релизами для Windows, macOS и Linux, а также iOS PWA. Уже используете ServerKit? Импортируйте `serverkit.yaml` из репозитория как новый сервис, и он развернётся одним выстрелом.
